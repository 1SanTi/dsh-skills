# 哔哩哔哩历史视频 → 微信联系人

> 坐标基准 2944×1840。B站是原生 App，坐标可用；微信「选择聊天」的头像列**别信 OCR 的 x**（见坑）。

## 步骤

```sh
# 0) 打开 B 站（会先弹广告，等它自己过或点「跳过」x≈2810 y≈1695）
scr launch tv.danmaku.bili

# 1) 我的 → 历史记录（我的页里这一行约 (1289,704)）
scr tap 1289 704

# 2) 历史页第一条就是最近看的视频，点它（行约 y≈444）
scr tap 1976 444

# 3) 视频页右下「分享」按钮（约 (2727,1714)）
scr tap 2727 1714

# 4) 分享面板第一项「微信」（约 (1075,1706)）
scr tap 1075 1706

# 5) 系统分享面板（com.zui.resolver）→ 微信（约 (1281,931)）
scr tap 1281 931

# 6) 微信「选择聊天」→ 最近转发第 n 个头像：
#    第 1 个 x≈119、第 2 个 x≈311、之后每个 +192；头像行 y≈549
scr tap 311 549

# 7) ★ 发送前必须截图核对底部「发送给: <名字>」和视频卡片标题
#    确认后再点绿色「发送」（约 (1646,1580)）

# 8) 成功标志：弹「已发送 ✓」，可选「返回哔哩哔哩 / 留在微信」
```

## 坑

1. **B站分享出去的是「视频卡片」**（标题+封面+播放量），不是视频文件；
   想要文件得先下载，那是另一条路。
2. 微信头像列**不能用 dump 里 OCR 的 x**：OCR 会把「三体」标成 x≈518，实际第 2 个头像在 x≈311。
   曾因此误点到别人，好在发送前截图核对了「发送给:」才发现。
3. 点错人不要紧：再点一次该头像即取消，只要没按绿色「发送」就还没发出去。
4. B站首次打开常有广告/未成年人模式弹窗：广告点「跳过」，未成年人模式点「我知道了」。
5. 微信对无障碍自动化有风控：必须在用户看着的时候做，一次一条。
