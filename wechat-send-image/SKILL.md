# 微信发图片（标准流程）

**一句话：不要用搜索框、不要用「文件」、不要用系统分享面板。就在聊天列表滑到人，点进去，+ → 相册 → 选图 → 勾原图 → 发送。**

## 前置

- 本机有两个微信：桌面 dock 左侧「微信」(主) 和右侧带橙色角标「微信」(分身)。
  **学法的联系人和「蓬源中学工作群」都在带角标的分身里**；`scr launch com.tencent.mm` 会弹「请选择」，
  点**右边带角标**的图标。选错会进另一个账号。
- 设备分辨率 2944×1808（截图 2944×1840），坐标换算 ≈ 截图坐标 ×1.83 得实际坐标。

## 步骤

1. **进聊天列表**：底部「微信」tab。必要时上滑/下滑左栏，直到看到目标联系人。
2. **点进聊天**：点头像行。**核对右侧标题栏**是这个人/这个群（别发错人）。
3. **点「+」**：输入框右侧 ＋（≈2886,1772）→ 弹出面板（相册 / 拍摄 / 语音通话 / 位置）。
4. **点「相册」**（≈1170,1569）。选择器打开，默认「图片和视频」，**最新的图在最前**。
   - 若要确认选的是哪张：点图 → 底部「预览」看大图 → 返回。
5. **选中图片** → 底部**勾「原图」**（≈1457,1732）。不勾会先压缩再传，容易长时间「正在发送中」。
6. **点绿色「发送」**（≈2816,1727）。
7. **核对结果**：气泡出现在右侧、无红色感叹号；返回列表该会话显示 `[图片] 时间`。

## 坑（都踩过）

- 顶部搜索框**不接受自动输入的文字**（中英文都不行），别在那里耗时间；用列表滑动找。
- 平板/折叠布局下「+」面板的**第 2 页（文件）滑不动**，不要指望它。
- 相册只列**媒体库已索引**的图片。手工 `cp` 到 `Pictures/Screenshots/` 的 PNG **不会**被索引；
  `shz am broadcast MEDIA_SCANNER_SCAN_FILE` 也没用。所以要用相册发自己生成的图，
  先让它在微信里出现过（比如先发给文件传输助手/自己，再从相册选），或改用其它通道。
- 发送大图会短暂显示上传圈，等几秒；只有红色感叹号才算失败。
- `shz am force-stop com.tencent.mm` 后重开偶发「无法连接到服务器(1,-15)」，等一会儿再试。
