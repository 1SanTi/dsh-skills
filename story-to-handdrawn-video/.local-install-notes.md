# 本机安装说明（story-to-handdrawn-video）

- 来源：GitHub `gnipbao/story-to-handdrawn-video`（main 分支），Skill 包取自仓库 `skill-package/story-to-handdrawn-video/`，项目本体（Remotion 工程）放在本目录根。
- 安装位置：`$DSH_HOME/skills/story-to-handdrawn-video/`
- 已省略的体积项：`references/style-examples/` 的整份示例图集（约 641MB，297 个样式 + 30 套调色板预览）与 `examples/`（约 20MB 演示素材）。仅取了默认样式的示例图与接触表（如已下载成功）。
- 本机补丁：`scripts/handdrawn-style-library.mjs`
  - 样式示例图缺失时降级为「无预览图」，不再整库抛错；
  - 接触表（contact_sheet）与调色板预览缺失时降级为 null。
  - 因此 297 个样式仍可按配方（prompt recipe）使用，只是多数没有视觉预览图。
- 渲染依赖：项目为 Remotion（Node + 无头 Chromium），需要 `npm install` 及可用的 Chrome。Android 上未尝试；建议在电脑上执行渲染，或先把整个项目拷到电脑。
- 常用命令：`node scripts/list-handdrawn-styles.mjs`（本地已验证可用，输出 327 项资产）；
  渲染入口 `python3 scripts/run_story_video.py` 或 `node scripts/story-to-video.mjs`（需先装依赖）。
