# WPS 文档 → 微信「以文件发送」

> 设备坐标基准：屏幕 **2944×1840**（ZUI 平板）。坐标会随 WPS 版本/字号变化，
> 每步都用 `scr dump` 核对文本后再点，不要盲点。

## 用法（人工确认版）

```sh
# 0) 自检 + 看当前在哪
scr idle 800 && scr dump | head -20

# 0.5) 目标文件不在「最近」里？用 WPS 搜索框（容器支持中文输入！）
#      tap 顶部搜索框 (1586,129)，再直接输入关键词：
scr input "回忆鲁迅先生" --target 搜索   # → {"ok":true,"chars":6}
#      结果每行右侧都有「分享」，x≈2775，y 取该行的坐标

# 1) WPS 首页「最近」列表：点这份文档行右侧的「分享」
#    行 y 由 dump 得到，分享按钮 x≈2790
scr tap 2790 <行的y>

# 2) 分享与发送 面板 → 底部「更多发送方式」→「以文件发送」（关键：不是「微信」图标，那个发的是链接）
#    面板里这一行可能在 y≈1230 或 y≈1295，以 dump 里的「以文件发送」节点为准
scr tap 921 1295

# 3) 底部弹层 →「发送给朋友」（云文档会先「正在获取文件 xx%」，等它到 100%）
scr tap 1471 431

# 4) 系统分享面板（com.zui.resolver）→「微信」
scr tap 1281 931

# 5) 微信「选择聊天」页 → 点「最近转发」里对应头像
#    头像行真实 y≈549；第 1 个头像 x≈119，第 2 个 x≈311，之后每个 +192
scr tap 119 549

# 6) ★ 发送前必须读屏核对底部「发送给: <名字>」和文件卡片
scr dump | head -20        # 或截图肉眼确认
#    确认无误后再点绿色「发送」
scr tap 1646 1580
```

## 发完怎么验证

- 微信会进入与该联系人的聊天页；
- 页面最下方出现 PDF 卡片（文件名 + `1.0 MB`），右侧（自己发的），没有转圈/红色感叹号；
- `scr dump` 里能看到这份文件的标题和大小。

## 坑（实测）

1. **OCR 的 x 坐标不可信**：dump 里 OCR 行给的坐标和头像列可能错位，
   曾把「小刘老师」点成了「三体」。头像列要按「最近转发」第一个 = x≈119 推算，
   第 n 个 ≈ 119 + 192×(n-1)。
2. **选错人可以改**：在「选择聊天」里再点一次该头像即可取消，底部「发送给:」跟着变；
   点错不要紧，**只要还没按绿色发送就还没有发出去**。
3. **`分享与发送` 面板里的「微信」图标发的是 kdocs 链接**，不是文件本身；
   要发文件本体必须走「更多发送方式 → 以文件发送」。
4. 微信对无障碍自动化有风控：**必须在用户盯着的时候做**，一次只发一份，不要批量连点。
5. 分享面板若没出现「更多发送方式」，先上滑面板；WPS 版本不同则用「发送给朋友 → 文件」路径。
6. **大文件**：实测 129.8 MB 的 pptx 微信也能收（先「上传中」，Wi-Fi 下约 5 分钟）。
   发之前确认在 Wi-Fi 上，别用流量；发完要等「上传中」字样消失才算成功。
7. 云文档会先「正在获取文件 xx%」（下载到本机），大文件要多等几十秒，别提前点取消。
