# 本机安装说明（srt-whiteboard-animation）

- 来源：GitHub `geeklee/srt-whiteboard-animation`（main 分支），整仓安装（约 12MB）。
- 安装位置：`$DSH_HOME/skills/srt-whiteboard-animation/`
- 已验证：`scripts/parse_srt.py` 可正常运行（Python 3.14，纯标准库）。
- 未完成：`scripts/prepare_env.py` 需要 `.venv` 内安装 opencv-python / numpy / av / Pillow。本机（Android + bionic）没有这些包的官方 wheel，源码编译代价高且大概率失败，因此渲染链路（`render_stream_whiteboard.py` 出 MP4）目前只在电脑上可用。
- 工作流里的「生成线稿」「标注分区」「打开预览台」等步骤不受影响，可以在本机做；只有最后的 MP4 渲染需要电脑。
