# 导出与交付复核

## 规格采集

投稿或会议交付前，查明目标方的实时官方要求：单/双栏宽度、高度上限、文件格式、色彩模式、位图分辨率、字体处理、文件大小和多面板规则。未找到官方要求时，记为未核验，不使用通用经验冒充合规。

## 格式选择

| 内容 | 优先格式 | 注意 |
| --- | --- | --- |
| 线条、文字、简单标记 | 矢量格式 | 嵌入字体，检查裁切框 |
| 显微图、卫星图、密集热图 | 无损或指定压缩的位图 | 按最终尺寸设分辨率 |
| 矢量与高密度位图混合 | 混合导出 | 只栅格化必要图层 |
| 演示文稿 | 可编辑源文件 + 预览 | 在实际投影尺寸下检查 |

## 结构复核

- 文件能打开，页面数、图号和面板数符合预期。
- 位图实际像素与物理尺寸支持目标分辨率，不是只改元数据标签。
- 字体可嵌入或已转为符合要求的轮廓，中文、希腊字母和数学符号不缺字。
- 数据点数、分组标签、坐标范围和图例项与生成数据一致。

## 100% 视觉复核

按最终尺寸查看完整边界、最密集面板、最小标注、图例、颜色相近组、误差带交叠和标签旋转位置。缩略图模式检查主结论是否仍可见，灰阶模式检查分组是否仍可区分。

## 交付清单

1. 最终图文件与可编辑源文件。
2. 生成代码、依赖版本、随机种子和参数。
3. 数据引用或可再生的中间数据，不重复散布多份手工修改表。
4. 图注、缩写表和已核验/待确认的交付规格。
5. 视觉复核范围与仍存限制。
