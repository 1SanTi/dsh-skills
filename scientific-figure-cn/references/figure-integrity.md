# 图表诚信检查

## 数据处理

- 保留原始数据、清洗后数据和绘图数据三层，不在原文件上直接修改。
- 所有排除、归一化、平滑、分箱、截尾和插补都有参数与理由。
- 缺失值、未检出、真零和无法测量分开编码。
- 样本排除规则先于看见结果设定；事后排除作为敏感性分析报告。

## 视觉编码

| 风险 | 检查 |
| --- | --- |
| 截断坐标 | 是否放大了差异；是否有明示和更合适图型 |
| 面积/体积编码 | 视觉大小是否与数值按正确维度比例变化 |
| 双轴 | 是否可通过分面、归一化或上下排列替代 |
| 平滑 | 是否同时保留原始观测，并写明窗口与边界处理 |
| 重叠 | 是否因遮挡少算了样本；是否需透明、抖动、密度或分面 |
| 色带 | 是否与有序/发散/无序数据匹配，中点和端点是否有语义 |

## 图像型数据

亮度、对比度和颜色调整应对整幅图像一致应用，局部处理需明确声明。裁切不能改变结论所需的上下文。拼接、删除背景、通道合并和放大区域保留边界与操作记录。上采样不得被描述为新增原始细节。

## 统计表达

显著性符号必须有对应比较、方法、双/单侧、多重校正和精确含义。不用星号替代效应量和不确定性。模型拟合线与原始点同时显示，超出观测范围的外推明确区分。

## 验收

让一名不参与绘图的人只看图和图注，回答“比较了什么、n 是什么、误差表示什么、哪些数据缺失、图能支持什么结论”。答案不一致时，优先修正编码和图注，不用口头解释弥补。
