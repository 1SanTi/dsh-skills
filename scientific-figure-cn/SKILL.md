# 科研绘图

## 能力定位

用“问题—数据—编码—不确定性—图注—交付”的完整链路制作科研图表。优先保证数据语义和可复现性，再追求视觉精致；图表应让读者看见数据的结构、差异和限制，而不是只看见作者希望强调的一点。

适合探索性分析图、单/多面板结果图、时序与分布图、模型评估图、图片型实验结果和学术海报图表。如果当前工具不能运行绘图代码或查看导出文件，应只交付图表规格和代码方案，不声称已完成视觉验收。

## 快速导航

- 担心坐标、平滑、缺失或图像处理误导：读取 [图表诚信检查](references/figure-integrity.md)。
- 需要投稿、印刷或答辩交付：读取 [导出与交付复核](references/export-review.md)。
- 只有数据没有明确图型：先写一句“读者看完应该回答什么”。
- 用户指定图型：先检查是否与变量类型和分析问题匹配，不盲从。
- 不知道目标期刊或展示尺寸：使用中性可编辑格式，将规格标为待确认。

## 新手30秒入门

提供数据文件、每列含义、研究问题、分组、统计量、目标媒介和尺寸。例如：“对比三组处理的细胞活性，展示每个样本、中位数和 95% 区间，用于双栏论文，不隐藏缺失。”

默认先返回 `图表任务卡`：读者问题、分析单位、变量类型、样本量、缺失口径、不确定性、建议图型、目标尺寸和输出格式。

## 功能索引

| 问题 | 优先编码 | 应补充的证据 |
| --- | --- | --- |
| 比较组间分布 | 点、箱/密度、分面 | 样本数、中心与区间 |
| 观察时间变化 | 位置与连续走势 | 缺失、采样频率、区间 |
| 看变量关系 | 散点、分组、密度 | 样本量、模型假设、异常点处理 |
| 展示组成变化 | 堆叠位置、小倍数 | 分母、总量与缺失分类 |
| 比较模型 | 误差分布、校准、决策曲线 | 数据切分、基线、不确定性 |
| 组合多个结果 | 对齐面板与共享标尺 | 面板逻辑、标签与图注引用 |

## 标准工作流

### 1. 锁定分析句

用一句话写清“对象、比较或关系、时间/范围、读者需要看见什么”。一张图承载多个无关问题时，拆成面板或多张图。

### 2. 建立数据字典

记录变量含义、类型、单位、分组、重复测量、检出限、缺失码和排除规则。变换、归一化、分箱和平滑都写入记录，不只保留图上的结果。

### 3. 区分分析单位

样本、视野、细胞、时间点和技术重复不能自动当成独立观测。图中的点、误差和 n 与真正分析层级保持一致。

### 4. 匹配图型与任务

先判断是比较、分布、关系、变化还是组成，再选位置、长度、面积和颜色等视觉通道。对重叠严重的散点使用透明度、抖动、密度或分面，不让遮挡造成虚假稀疏。

### 5. 显式展示缺失与不确定性

区分标准差、标准误、置信区间、预测区间和数据范围。图注说明误差带含义和计算单位。时序缺失不默认连线，排除样本不从图中静默消失。

### 6. 设计视觉层级

把数据放在最高对比度，网格、边框和次要注释降级。颜色用于表达少量稳定类别，同时用形状、线型、标签或分面提供冗余编码，不只靠色差。

### 7. 组织多面板

按阅读顺序排列，统一尺寸、字号、线宽、图例和缩写。需要直接比较的面板共享坐标范围；不共享时显式标出，防止读者错误对比。

### 8. 写自包含图注

图注说明样本、处理、编码、n、误差、统计方法、缩写和面板顺序。不在图注里宣称图本身无法支持的机制或因果。

### 9. 按最终尺寸导出

先设目标宽高，再调整字号、标记和线宽。需编辑的线条优先保留矢量格式；包含大量像素的图使用合适分辨率的位图。不用放大小图的方式伪造细节。

### 10. 双通道复核

结构复核检查数据、单位、对象数量、字体和文件属性；视觉复核在 100% 最终尺寸检查裁切、重叠、锯齿、字形缺失、颜色区分和缩略图可读性。

## 输出规范

每张图交付：

- `图表意图`：一句话说明读者应回答的问题。
- `数据口径`：分析单位、n、缺失、排除、变换和时间范围。
- `编码说明`：位置、颜色、形状、线型、误差和面板的含义。
- `图注`：能脱离正文理解，不重复标题。
- `交付包`：图文件、可复现代码、数据或明确数据引用、参数与环境记录。

文件名包含图号、内容、版本和格式，例如 `fig02-response-v03.pdf`。导出位图不覆盖可编辑源文件。

## 能力边界

- 图表可视化已有分析，不能弥补抽样、实验设计或统计方法的根本缺陷。
- 不通过截断坐标、不等比面积、不透明平滑或选择性排除夸大结论。
- 未知目标期刊、学校或会议的实时规范时，不声称“已符合投稿要求”。
- 不伪造原始数据、误差、p 值、显著性标记、显微图细节或重复实验。
- 医疗、药物和安全关键结果需领域专家审查，不因图表美观而降低证据门槛。

## 稳定性保障

原始数据只读保留，清洗、变换和绘图分层生成。记录数据版本、环境、随机种子、字体、画布尺寸、色板和导出参数。任何人修改缩放、排除或色标都应能在代码或参数文件中追溯。

对标签、图例和数据对象数量做结构检查；对每种最终格式至少打开一次。多页或多图交付应抽查第一张、最密集的一张和最后一张；发现缺陷后重新导出，不只修改预览图。

## 深度定制

生命科学图像保留比例尺、处理范围和通道说明；地理数据保留投影、空间分辨率和无数据区；时间序列显式处理不规则采样与缺口；机器学习图保留数据切分、基线和校准；海报或答辩版在更大阅读距离下减少元素，但不删掉关键限制。

## FAQ

**条形图一定要从零开始吗？** 长度表达数值时通常应从零开始。不从零开始必须有清晰理由和显眼说明，并评估是否改用点图。

**误差条用哪一种？** 取决于要表达观测离散、估计不确定性还是预测范围。必须在图注中写明。

**颜色好看就行吗？** 不行。颜色要与数据语义匹配，并在色觉差异、灰阶打印和投影环境下仍可区分。

**可以从截图里反推精确数据吗？** 只能做标明误差的近似数字化，不得当成原始数据或声称精确复原。

## 反模式与修正

| 反模式 | 修正 |
| --- | --- |
| 先选“好看的图”再填数据 | 先定义读者问题和变量类型 |
| 只展示均值柱子 | 展示原始分布、n 与合适区间 |
| 时序缺口直接连线 | 显式断开或标注插补方法 |
| 用彩虹色带表示无序类别 | 使用离散色板并增加冗余编码 |
| 导出后只看编辑界面 | 用最终软件和目标尺寸打开交付文件 |
