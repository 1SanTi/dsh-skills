# 录音转文字｜本地转写·会议字幕

**把会议、访谈、课程录音，变成可查阅的文字稿和字幕文件。普通本地转写无需云端 API Key，音频不由本脚本上传云端。**

第一次使用需安装运行环境并准备模型；模型下载完成后，普通转写可用 `--offline` 只读缓存运行。说话人分离与云端转写是按需配置的进阶选项。

## 直接这样用

- **会议文字稿：**“把这段 m4a 录音转成带时间戳的文字稿，先用本地模式。”
- **课程字幕：**“把这段 mp4 的语音做成 SRT 和 VTT 字幕，不翻译。”
- **长录音试转：**“先试转开头 30 秒，查看效果，再决定是否转全文。”
- **多人访谈：**“区分不同说话人，已知有 3 人；不要猜姓名和职务。”

输出示意（非实测录音）：
```text
[机器转写，未经人工校对；专名、数字、承诺和结论须回听原音频核实]
[00:00:02.000–00:00:05.000] 下周三提交修订方案。
```
开启说话人分离且识别到标签时，文字稿会附 `[SPEAKER_00]` 等中性标记。标签可能有误，不能据此推断真实身份。

## 执行流程

1. 定位用户提供的本地音视频文件。没有音频、仅要求根据已有文字稿写纪要或润色时，不调用转写脚本。不自动下载网页、绕过访问限制或调用第三方音频服务。
2. 使用宿主当前可用的 Python，进入本 Skill 目录，运行 `python scripts/check_env.py`。安装和执行须使用同一解释器；不要套用作者电脑路径。报告区分“发现依赖”和“真实转写通过”。环境缺失时读 [安装与进阶配置](references/install.md)，在当前任务权限内处理依赖。
3. 普通转写优先 faster-whisper，默认 `small`、中文 `zh`、CPU `int8`，无需云端密钥。英文设 `--lang en`；不确定语种或混合语种可设 `--lang auto`，结果仍需抽查。已有 WhisperX 环境且没有 faster-whisper 时可使用 WhisperX。
4. 用户只要试转时加 `--preview-seconds 30`；未经其要求，不把每次完整转写强制拆成需要反复确认的流程。试转和全文结果必须明确区分。用户要区分说话人时加 `--diarize`，读安装说明中的对应条件；失败时说明原因，不擅自交付普通版本冒充说话人版本。
5. 依据成功回执交付实际生成的文件，说明引擎、全文/试转、是否上云、是否区分说话人及待校对状态。回执为 `no_speech_detected` 或命令失败时，不声称已完成转写；先检查录音能否播放、是否静音、依赖或模型是否就绪。

## 最少命令

```bash
python scripts/transcribe.py "会议录音.m4a"
python scripts/transcribe.py "课程.mp4" --formats txt,md,srt,vtt
python scripts/transcribe.py "访谈.wav" --preview-seconds 30 --output-dir ./outputs
```

以上路径和文件名为示例。宿主的解释器若不是 `python`，替换为实际解释器路径。每次运行都在输出父目录下建立新的 `asr_...` 子目录，保留之前的转写和源文件。结果格式、退出码和示例见 [输出与交付](references/output-format.md)。

## 质量与进阶选项

- `small` 降低首次运行负担，不保证达到大模型精度。录音嘈杂、专名较多时可尝试 `--model large-v3`；更耗内存与时间。`--hint-words "术语A，术语B"` 只作提示，不能替代核对。
- 长录音能否顺利处理取决于内存、模型、引擎及音频质量。本地没有承诺按 1.5 小时自动切文件；可先试转，必要时降低模型，或按用户要求分段。OpenAI 文件超过阈值时的切块仅属于该云端适配器，不适用于全部路径。
- 保留机器原稿。校对时另存“校对稿”和“待核对清单”，人名、金额、日期、承诺不能凭上下文补成事实。不把 ASR 原稿当作已核实会议结论。
- 本地失败不会自动上传云端。仅在用户已同意把该音频发给所选服务商后，才使用 `--engine cloud`；已有授权无需重复确认。云端配置见安装说明，可能收费；不承诺某服务商天然满足客户合规要求。涉密录音采用符合其管理要求的本地环境。
- 用户要求纪要或访谈分析时，在转写之后继续完成该目标；仅在相关下游 Skill 已安装且适用时调用。普通文字稿和字幕交付不依赖其他 Skill。文件用宿主可用的附件或链接方式交付，不假定必须有特定展示工具。
