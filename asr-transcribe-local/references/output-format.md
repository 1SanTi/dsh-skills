# 输出、回执与故障排查

## 每次运行的文件

`--output-dir` 指向父目录，结果放入新建的 `asr_...` 子目录，避免覆盖原稿。源音频不改写、不删除。默认 TXT+SRT；可选 `--formats txt,md,srt,vtt,json`。

| 文件 | 用途 |
|---|---|
| TXT / MD | 带时间戳和待校对提示的文字稿；说话人模式按实际标签标注 |
| SRT / VTT | 标准字幕时间轴；不等于已压入视频，也不自动翻译 |
| JSON | 片段 start/end（秒）、text、speaker（可为空）与待校对说明 |
| run-receipt.json | 实际引擎、是否上云、全文/试转、片段数、实际产物列表、未标注说话人片段数 |

`duration_seconds` 是引擎/音频返回的可用时长；无法取得时为 null，不能拿最后一句结束时间冒充总时长。`preview_seconds` 是请求的试转上限；源文件更短时实际时长更短。

## 状态与退出码

| 退出码/状态 | 含义与处理 |
|---|---|
| 0 / completed | 完整输入的转写流程完成，仍需抽查原音频；不是准确率认证 |
| 0 / preview_completed | 仅试转开头片段，不得称整段完成 |
| 3 / no_speech_detected | 引擎没有返回非空语音片段，仅保留回执；检查静音、噪声、解码、语种与模型 |
| 1 | 依赖、引擎或服务失败，未完成；根据安装说明修复 |
| 2 | 输入、参数或结果时间戳不合法，修正后重试 |

## 交付原稿与校对稿

机器原稿必须保留。需要校对时另存新稿，同时列出待核对的专名、金额、日期等，不凭常识替录音补事实。转写后要整理纪要时继续用户目标；只要字幕时直接交付字幕，不强加其他流程。

## 常见失败

- 没有 Python/引擎：安装 Skill 不会自动附带模型，先按安装说明准备同一解释器环境。
- 普通转写提示需要 Key：确认没有误选 `--engine cloud` 或 `--diarize`；普通 faster-whisper 不需要云端 Key。
- 模型下载失败：确认网络、磁盘或本地模型路径；`--offline` 且未缓存模型时失败是预期行为。
- 卡顿/内存不足：先试转，降低模型；WhisperX 可降低 batch-size。不要承诺长录音一定成功。
- 说话人结果不完整：回执会列无标签片段数；不得自行补姓名、合并各段编号或忽略失败。
- 字幕没有翻译/烧录到视频：本 Skill 输出的是转写文本和字幕文件，翻译与字幕压制属于另一个任务。
