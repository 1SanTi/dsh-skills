# 湖南学法网学法任务

2026 年度湖南学法（hn.12348.gov.cn）的「学法」部分不含视频：读《2026年度〈九五普法导读〉（一）（二）》两个读本、共 16 章 100 道章节测验题，**答对 1 题 = 1 学分**，满分 100 即同时满足总学分 100 / 必修 20，取得考法资格。

## 一、准备

- 每账号需要：手机号 + 密码（各省内单位密码多为统一初始密码，如 `<单位初始密码>`）
- 脚本目录：`~/skills/hunan-xuefa/scripts/`（`xfkf.mjs` 主脚本、`proxy.mjs` 取证反代）
- 答案库已内置在 `xfkf.mjs` 的 `ANS` 表里（章号 → 每题答案）；**多选题必须写成 `A,B`**，写成 `AB` 会被判错。

## 二、标准流程（纯接口，几分钟）

全部命令在该 skill 的 `scripts/` 目录下执行。

```bash
cd ~/skills/hunan-xuefa/scripts
PHONE=<手机号>

# 1) 取图形码（4 位数字），脚本会把图片存成 captcha-<手机号>.jpg
node xfkf.mjs captcha $PHONE
#    → 用 read_image 看这张图（必要时放大：magick x.jpg -resize 400% -colorspace Gray -normalize out.png）
#    → 读出 4 位数字，例如 3412

# 2) 登录
node xfkf.mjs login $PHONE '密码' 3412

# 3) 看当前学分/单位（确认登录的是要做的那个账号）
node xfkf.mjs status $PHONE

# 4) 一把交卷：自动跳过已答对的题，返回 score / pubZs / examOpen
node xfkf.mjs answer $PHONE
```

正常输出：`{"submitted":100,"wrongLeft":0,"score":100,"pubZs":100,"examOpen":false}`。
`examOpen:false` 表示考法（考试）还没排考——`/rufawebsite/` 是独立的「湖南省国家工作人员学法考试平台」，需另行登录，等开放。

## 三、取证截图（给用户看/发微信）

不要重新登录浏览器（图形码难认、步骤多）。用反代把已有 cookie 注入后直接渲染真实页面：

```bash
node proxy.mjs $PHONE 3210        # 后台常驻：127.0.0.1:3210 -> https://hn.12348.gov.cn（带 cookie）
```

- 浏览器打开 `http://127.0.0.1:3210/fxmain/study`
- 页面会显示 姓名 / 单位 / 学法积分（总学分 100 已达标、必修已达标）/ 学法进度（60 + 40 学分）
- `scr shot --save` 截图，再把图放进相册：`cp 截图 /storage/emulated/0/Pictures/Screenshots/Screenshot_日期_说明.png`

## 四、发微信（按用户录制的步骤）

1. 微信 → 搜联系人 → 打开聊天 → 核对标题栏是本人/本群
2. 「+」→ **相册**（微信图片选择器只认媒体库相册，直接放 Download 里找不到）
3. 选中最新的那张截图
4. **勾选「原图」**（不勾会先压缩再传，卡在"正在发送中"很久）
5. 绿色「发送」→ 确认气泡出现、无红色感叹号

## 五、坑（实测）

- 多选题答案分隔符：必须 `A,B`；写 `AB` 判错（首轮会错一批，`answer` 会自动补答）。
- 答案文档笔误：四、湖南省行政执法监督条例 第 1 题，WPS《2026学法.docx》写 `AB`，但平台是单选，条例第二十二条原文为「反映」→ 应选 **A**。已内置修正。
- 图形码：4 位数字 + 一条干扰斜线，用 read_image 直接看，放大灰度更清楚；错一次只提示「验证码不正确」，可重新取。
- 学分是**按题计**，不是按读本/时长，所以 100 题一次提交完就等于满分，不需要挂机看课。
- 浏览器取证页的头像图可能显示破损（反代下静态图路径差异），不影响学分数字的取证。
- 微信：平板/折叠布局下「+」面板第二页（文件）滑不动，直接用「相册」。
